# Test suites

What each suite covers. CLAUDE.md keeps the testing policy and env knobs.

- **Rust (`cargo test`):** `workbench-core` units, the `workbench` desktop crate units (dispatchers, `server_control` mock-runtime), `workbench-server` units, and `apps/server/tests/server.rs` (e2e: real server on an ephemeral port, driven with reqwest + a `tokio-tungstenite` WS client). The e2e suite covers the cwd allowlist (`/agent/files`, a `newSession` in an unknown worktree), server-built Claude commands, the removed lifecycle routes answering 404/405, the terminal cap, bearer auth (no/wrong token → 401 on HTTP and WS, weak token refused), foreign-`Origin` WS rejection (403), two listeners sharing `Managers`, and WS-close on kill **and** on shell exit. Every embedded test server needs a ≥32-char token (`TOKEN` const + `client()` / `ws_url()` helpers).
- **JS (`turbo run test`):** `@workbench/transport` (HTTP route mapping, undefined-param dropping, error handling, `MockTransport`, `/events` reconnect backoff, `terminalWsUrl`, **and the `TauriTransport` shim** — `tauri.test.ts` mocks `@tauri-apps/api/{core,event}` to assert the omit-args-when-undefined call shape + listener wiring), `@workbench/control-plane-ui` (`ControlPlaneStore` via `createMockTransport`), `@workbench/desktop` (stores/utils via injected `createMockTransport`; `InstancesStore`/`RemoteInstance`), `@workbench/chat-ui` (`AgentChat` with a fake socket, chat formatting, image intake), and **`@workbench/mobile`** (jsdom vitest: `MobileClient` in `client.svelte.ts` — extracted from `App.svelte` so the connection/terminal/chat logic is unit-testable — terminal reconnect status, home-screen labels, and the workspace stream and commands with a fake `EventSource` in `client-workspace.test.svelte.ts`). Mobile component rendering (xterm) is intentionally not tested; the logic lives in the store/helper.
